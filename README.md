# 교사 생존 배터리 & 방학 D-Day

한국 선생님을 위한 데스크 친화형 생존 대시보드입니다. 한국 표준시(KST) 실시간 시계, 요일별 시간표 레이더, 교시·쉬는 시간·하교 전환 알림, 학기 생존 배터리와 방학 D-Day를 한 화면에서 제공합니다.

- 라이브 사이트: <https://thehuihuifam.github.io/school-survival-clock/>

## 주요 기능

### 시계 · 카운트다운
- 아시아/서울(KST) 기준 1초 단위 라이브 시계. 디바이스 시간대와 무관하게 동작
- **드래프트 프리 타이머**: 전용 Web Worker가 초 경계에 맞춰 틱을 생성하고, 탭이 숨겨져 있어도 시간이 밀리지 않음. Worker를 쓸 수 없는 브라우저에서는 동일 알고리즘의 메인 스레드 폴백 + `visibilitychange` 즉시 재동기화
- 현재 국면(등교 전 / 교시 진행 / 쉬는 시간 / 공백 / 하교 완료)에 맞는 메인 카운트다운과 하루 진행률 바
- 주말·공휴일(내장 달력 자동 적용)·방학·개학 전 상태를 자동 감지해 "다음 등교까지" 카운트다운으로 전환
- **예비종(0교시 벨)**: 다음 교시가 1/3/5/10분 앞으로 들어오면 "예비종" 상태로 전환되고 차임·알림이 함께 울림 (설정에서 끄거나 간격 변경)
- 카운트다운 카드를 누르면 자동 표시 ↔ 현재 블록 남은 시간 ↔ 하교까지 남은 시간으로 전환
- 카운트다운 문구는 상태·블록·시각을 한 줄로 합쳐 읽습니다(예: `6교시 수업 · 14:10 ~ 14:50`). 날짜도 `2026년 9월 17일 목요일` 한 줄입니다

### 시간표 레이더
- **요일별 커스텀 시간표**: 교시 이름·구분(수업/점심/재량·동아리/방과후)·시작/종료 시각을 직접 편집
- 초등 6교시 / 중등 7교시 / 고등 7교시+자습 / 단축 4교시 프리셋, 요일 간 복사, 시간순 정렬
- 쉬는 시간은 교시 사이 5분 이상 간격에서 자동 생성, 마지막 교시~퇴근 시각은 방과후·업무 블록으로 표시
- 타임라인 위에 실시간 플레이헤드, 블록별 진행률, 완료/진행/예정 상태
- 다음 일정 레일: 지금 진행 중인 블록과 다음 일정 3건의 카운트다운 (하교 후에는 다음 등교일 자동 미리보기). 예비종 구간에 들어간 일정은 `예비종` 칩으로 강조
- **오늘 하루 예외**: 재량휴업·단축 하교처럼 그날만 다른 일정을 히어로 카드에서 한 번에 적용/해제 (날짜가 바뀌면 자동 만료)

### 이번 주 한눈에 보기
- 월~일 7일을 같은 규칙(학기/방학·공휴일·하루 예외·요일별 시간표)으로 평가해 수직 캡슐 막대로 요약(오늘은 Action Blue)
- 요일별 교시 수와 하루 범위, 남은 수업일, 주간 수업 시간 합계, 가장 빡센 날 강조. **하교 시각이 지난 오늘은 남은 수업일에서 제외**합니다
- 단축 수업일에는 카드·토스트·축하 알림이 모두 실제 하교 시각(`dismissalTimeFor`)을 표기합니다

### 알림 · 축하
- 교시 시작·쉬는 시간·점심·방과후·하교 전환 순간에 **Web Audio 차임벨** (파일 다운로드 없음)
- **음량 조절 슬라이더**(0~100%)와 미리 듣기 버튼
- 옵션으로 **브라우저 알림** (기본 꺼짐, 권한 요청 후 활성화). 오래 전에 지나간 전환은 재생하지 않음
- 하교 시각 도달 시 캔버스 컨페티 + 축하 토스트 (컨페티는 코드 스플릿으로 분리, 하교 순간에만 로드)

### 학기 배터리 · 지표
- 학기 시작일 → 방학 시작일까지 **수업일 기준** 충전율 (주말·등록 휴일 제외)
- 방학 D-Day, 남은 수업일, 오늘 남은 교시/수업 시간, 하루 진행률, 주간 리듬(며칠차·쉼까지), 통계 스트립
- **학기 자동 갱신**: 기본값이 한국 학사일정(1학기 3/2~7/20, 2학기 8/18~다음 해 1/6)을 따라 오늘 기준으로 자동 계산되므로 해가 바뀌어도 방학 모드에 갇히지 않음. 직접 입력 모드로 전환하면 기존처럼 수동 지정
- **법정 공휴일 자동 적용**: 2025~2029년 대한민국 공휴일(설날·추석 연휴, 부처님오신날, 대체공휴일, 선거일 포함)을 내장 달력으로 자동 반영. 직접 등록한 날짜가 항상 우선하며, 설정에서 끌 수 있음
- 재량휴업일·체험학습일 직접 등록, 수업 요일 선택
- 오늘 하루 예외(휴업/단축)는 배터리·주간 리듬·다음 등교일 계산에 모두 반영

### 설정 · 데이터
- 설정은 localStorage에 자동 저장, **다른 탭과 실시간 동기화**, 스키마 검증·마이그레이션(v1 → v4) 내장: 예전 기본 학기(2026-08-25/2026-12-31)만 저장돼 있던 설정은 자동 모드로 승격되고, 직접 지정한 날짜는 그대로 보존됨
- 설정 JSON 내보내기/불러오기, 기본값 초기화
- 다크/라이트/시스템 테마(**현행 v4 저장 키까지 읽는 프리페인트 부트스트랩**으로 첫 프레임부터 올바른 테마, FOUC 없음), 키보드 단축키(`S` 설정 · `T` 화면 모드 · `F` 전체 화면 · `M` 소리 · `N` 알림) — 모두 실제로 동작

### 복원력 · PWA
- 서비스 워커: 앱 셸 프리캐시 + 해시 에셋 stale-while-revalidate + 내비게이션 network-first → **오프라인에서도 동작**
- Web App Manifest·아이콘 포함, 설치 가능(바탕화면 앱), `?open=settings` 딥링크
- 네트워크 끊김 시 헤더에 오프라인 표시등

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

품질 점검:

```bash
npm run icons      # src에서 참조된 Solar 아이콘을 인라인 SVG 맵으로 생성
npm run icons:app  # public/icon-*.png, apple-touch-icon.png 래스터라이즈 (의존성 없음)
npm run typecheck  # tsc -b (strict)
npm test           # vitest 단위 테스트 (스케줄 엔진·학기 수학·설정 정규화 등)
npm run build      # icons → typecheck → vite build
npm run preview    # 프로덕션 빌드 미리보기
```

앱 아이콘(`public/icon-*.png`)은 `scripts/generate-app-icons.mjs`가 의존성 없이 래스터라이즈합니다. 수정이 필요하면 `npm run icons:app`을 실행하세요.

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 **typecheck → 단위 테스트 → 빌드 → Pages 배포**를 순서대로 실행합니다.

- 배포 주소: `https://<github-사용자명>.github.io/school-survival-clock/`
- 프로덕션 빌드는 `base: './'`(상대 경로)를 사용하므로 하위 경로 어디에서도 동작합니다. 정적 리소스(CSS/JS/워커/매니페스트/아이콘)는 모두 문서 기준 상대 경로로 해결됩니다.
- 최초 1회는 저장소 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 지정해야 합니다.
- 수동 재배포는 Actions 탭에서 **Deploy to GitHub Pages** 워크플로를 `workflow_dispatch`로 실행하세요.

```
src/
  lib/
    time.ts        KST 변환·파싱·포맷 + 한국어 조사 처리 (순수 함수)

    semesterWindow.ts 한국 학사일정 기반 학기 창 계산(1학기/2학기 자동 전환, 방학 경계를 넘는 탐색)
    schedule.ts    요일별 시간표 → 블록/쉬는시간/상태, 휴일·방학 판정, 하루 예외(휴업/단축), 다음 일정 탐색
    semester.ts    수업일 기반 배터리 수학
    weekOverview.ts 이번 주 월~일 7일 요약 (수업일·부하·상태)
    timeline.ts    타임라인 레이아웃(비율·플레이헤드)과 NEXT UP 프로젝션
    settings.ts    localStorage 저장·검증·마이그레이션·내보내기/불러오기·탭 동기화
    useNow.ts      Worker 기반 드래프트 프리 1Hz 틱 (+ 폴백)
    tick.worker.ts 배경 탭에서도 살아 있는 하트비트 워커
    alerts.ts      전환 감지(오래된 이벤트 억제) + 예비종 감지 → 차임/알림 디스패치
    sound.ts       Web Audio 차임 합성
    notify.ts      Notification API 래퍼
    theme.ts       테마 해석·시스템 선호 추적
    pwa.ts         서비스 워커 등록·설치 프롬프트
  components/      화면 컴포넌트 + settings/ (탭형 설정 에디터, 포커스 트랩)
  lib/__tests__/   vitest 단위 테스트
scripts/           아이콘 생성기 (SVG 인라인 맵, PNG 앱 아이콘)
```

## 변경 이력

### v2.3.0 — Apple Design System 전면 이식 · 대화면 가독성 · 결함 패치
- **디자인 시스템 교체**: 에메랄드·네온 액센트와 배경 메시 그라디언트를 전부 걷어내고 Action Blue 단일 액센트 + 헤어라인 카드로 재구성했습니다. 본문 17px/-0.374px, Apple tight tracking, Pill 버튼과 `scale(0.95)` 마이크로 인터랙션, `saturate(180%) blur(20px)` 프로스티드 내비게이션을 적용했습니다.
- **대화면(PC·교실 TV) 가독성**: 시계 `clamp(64px, 7vw, 96px)`, D-Day 40px/600, 본문·레이블 15~17px, 타임라인 최소 폭 720px·높이 96~104px, 넓은 카드 패딩과 안전 영역 대응. 작은 화면에서는 4열 주간 그리드와 12px 여백으로 줄입니다.
- **문구·위젯 정리**: 히어로 날짜 2줄 중복을 `2026년 9월 17일 목요일` 한 줄로, 카운트다운 3중 중복(`6교시 수업 중` / `6교시` / `14:10 ~ 14:50 · 75% 지남`)을 `6교시 수업 · 14:10 ~ 14:50` 한 줄로 합쳤고, 시간표 카드의 사족 안내문을 삭제했습니다.
- **데드 코드 제거**: 스타일이 없던 `.reveal-on-scroll`·`--index`·`hero-tone-*`·`battery-tone-*`·`theme-*`·`background-mesh`를 JSX와 CSS 양쪽에서 삭제, 미사용 `@keyframes float-soft`와 `formatKstDate()`, `ClockHero`의 중복 `hms()`, 중복 `notify` import, 사용하지 않던 Geist 폰트 요청 1건을 정리했습니다.
- **결함 패치**: (1) 프리페인트 부트스트랩이 현행 `settings.v4` 키를 1순위로 읽도록 수정해 라이트 모드 새로고침 깜빡임(FOUC)을 제거, (2) 주간 카드의 남은 수업일이 하교 후에도 오늘을 세던 문제 수정, (3) `handleToggleSound`/`handleToggleNotify`의 상태 업데이터 내부 부수효과를 밖으로 빼 React StrictMode 이중 실행 위험 제거, (4) 단축 수업일 하교 시각 표기를 실제 시각으로 통일.
- **아이콘·캐시**: 앱 아이콘 PNG/ SVG를 Action Blue 팔레트로 재생성, 서비스 워커 캐시 `survival-clock-v7`로 범프.
- **실사용 잔여 결함 마감(D-3 · D-2 · D-6)**: (1) 하교를 마친 뒤에도 NEXT UP 레일이 오늘 시간표를 지난 교시까지 되살리던 문제를 수정 — 앵커를 '내일 이후의 등교일'로 밀고(`App`), 폴백에서 오늘 날짜를 통째로 건너뛰며(`timeline`), 레일 중복 키에 날짜를 포함했습니다(`PeriodTracker`). (2) 하교 시각을 마지막 교시보다 이르게 입력하면 엔진이 `Math.max`로 조용히 늘려 버리던 문제에 대해 설정 프로필·시간표 탭에 이유와 대안(홈 화면 `단축 하교`)을 인라인으로 안내합니다. (3) 버전 표기를 `package.json`·lockfile 모두 **2.3.0**으로 통일했습니다.
- 테스트 141 → 155개(날짜 단일화·카운트다운 축약·단축 하교 표기·주간 잔여일 회귀 케이스 추가, D-3 하교 후 유령 일정·D-2 하교 시각 안내 회귀 케이스 추가).

### v2.2.0 — 공휴일 내장 달력 · 주간 요약 · 한국어 카피 정리
- **법정 공휴일 자동 적용**: 2025~2029년 공휴일을 `lib/holidays.ts`에 내장했습니다. 음력 명절(설날·추석 연휴)과 부처님오신날, 대체공휴일, 선거일까지 포함하며 직접 등록한 휴일이 항상 우선합니다. 교사가 출근하는 근로자의 날·제헌절은 제외했습니다.
- **이번 주 한눈에 보기 카드**: 월~일 7일의 교시 수·수업 부하·상태를 막대로 요약하고, 남은 수업일과 가장 빡센 날을 알려 줍니다.
- **차임벨 음량 조절**: 0~100% 슬라이더와 미리 듣기 버튼을 설정에 추가했습니다.

## 디자인 시스템

Apple Design System을 기준으로 구현했습니다. 모든 토큰은 `src/index.css`의 `:root[data-theme]` 한 곳에 있습니다.

- **컬러**: 인터랙티브 액션 컬러는 Action Blue 단 하나입니다(라이트 `--primary: #0066cc`, 포커스 링 `#0071e3`, 다크 `#2997ff`). 캔버스는 라이트 `#ffffff` / `#f5f5f7`, 다크 `#000000` / 타일 `#272729`·`#2a2a2c`이며, 카드는 그림자 대신 `1px` 헤어라인(`--hairline`)과 면 색 차이로만 구분합니다. 장식용 그라디언트·메시·네온 글로우·박스 섀도는 코드에 존재하지 않습니다. 상태색(경고·위험·성공)은 의미 전달에만 쓰고 Apple 시스템 컬러를 씁니다.
- **타이포그래피**: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", Pretendard, sans-serif`. 본문은 **17px / `line-height 1.47` / `letter-spacing -0.374px`**, 17px 이상 제목은 `-0.374px ~ -0.28px`의 음수 자간(Apple tight tracking)을 씁니다. 굵기는 300 / 400 / 600 / 700만 사용합니다(본문 400, 헤드라인 600).
- **버튼·칩**: 모든 주요 버튼·칩·세그먼트·모달 탭이 Pill 라디우스(`9999px`)이고, 누를 때 `transform: scale(0.95)` 마이크로 인터랙션이 `0.12s`로 들어갑니다. 최소 터치 높이는 44~48px입니다.
- **내비게이션**: 상단 바는 높이 52px(`48px` 이하 화면), `backdrop-filter: saturate(180%) blur(20px)` + 하단 1px 헤어라인의 Apple `global-nav`/`sub-nav` 스타일입니다.
- **아이콘**: Iconify Solar 세트를 **빌드 타임에 인라인 SVG로 생성**(`npm run icons`)합니다. 런타임 CDN 스크립트와 아이콘별 네트워크 요청이 없고, 오프라인에서도 아이콘이 보입니다.
- **모션**: `transform`/`opacity`만 사용합니다. 카드 진입은 `fade-in` 한 가지 키프레임이고, 게이지·배터리·타임라인 진행은 `width` 대신 `transform: scaleX(var(--fill))`입니다. 모든 모션은 `prefers-reduced-motion`에서 해제됩니다.
- **뷰포트·대화면**: 높이 기준 `100dvh`, 콘텐츠 `max-width: 80rem`(1440px 이상 `88rem`). 교실 TV·데스크톱(1024px 이상)에서는 시계가 `clamp(64px, 7vw, 96px)`, 타임라인 높이 104px, 카드 패딩 32px로 커지고, 안전 영역(`env(safe-area-inset-*)`)을 반영합니다.
